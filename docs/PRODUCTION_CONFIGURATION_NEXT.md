# المرحلة التالية بعد نشر مراجعة 22 أكتوبر 2026

طلب المالك إكمال هذه الإعدادات بعد رفع تصحيحات الواجهة ومزامنتها مع CMS. يبدأ العمل بتثبيت القيم والوجهات الحالية ثم تنفيذ الربط وفحصه، دون اختراع منتجات أو أسعار أو مستلمين.

- ربط الموقع بالدومين النهائي ووجهة www، مع مراجعة DNS وSSL وإعادة التوجيه وcanonical وخرائط الموقع.
- مراجعة إعدادات Cloudflare وربط Turnstile للنماذج، وإضافة نطاقات التشغيل الصحيحة.
- إعداد بريد الموقع، ومستلمي النماذج، وعنوان المرسل وReply-To، وسجلات SPF وDKIM وDMARC، وفحص وصول الطلبات فعلياً.
- تجهيز منتجات WHMCS ومعرفاتها وفترات الدفع والأسعار المعتمدة، ثم ربط أزرار الخطط بالمنتجات الصحيحة.
- ربط بحث الدومينات بالمسار والخدمة المعتمدين، وفحص نتائج التوفر والانتقال للشراء.
- حسم وجهة «الاستضافة» الرئيسية: بقي البند السابق معلقاً لأن صفحة مستقلة لم تكن موجودة، والمالك لا يقصد بوابة hosting.codeyea.com ولا صفحة Website Hosting.
- إكمال تهيئة دخول CMS الإنتاج لحساب المالك وصلاحياته عبر المسار المعتاد؛ قراءة قاعدة الإنتاج في هذه الدفعة أظهرت عدم وجود مستخدمين أو أدوار. لم تُنشأ حسابات أو تُغيّر صلاحيات ضمن تصحيحات المحتوى.

تُدخل الأسرار من خلال واجهات الإعداد الآمنة، ولا تُحفظ في Git أو مستندات المراجعة.
