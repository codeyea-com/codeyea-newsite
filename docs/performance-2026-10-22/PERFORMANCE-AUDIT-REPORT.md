## القياسات

هذه نتائج مختبر Lighthouse 13.5.0 من هذا الجهاز، مع throttling افتراضي محاكى. لا تمثل Core Web Vitals ميدانية، ولم يُستنتج INP من TBT. أعاد PageSpeed API المشترك 429، لذلك استُخدم Lighthouse CLI مباشرة.

## حدود النتيجة

أداء الموبايل العربي ما زال 72، وLCP المختبري 4.0s وTBT 0.5s. الموبايل الإنجليزي أيضًا أعلى من هدف LCP البالغ 2.5s. الأداء لم يصل إلى 100 على الموبايل؛ بقيت ملاحظات CSS وحزمة JavaScript الخاصة بالإطار. لا تضمن نتائج المختبر تجربة كل زائر، ولا تعني اختبارات الوصول التلقائية اكتمال مراجعة يدوية لجميع الحالات.

حركات الهيرو وتوقيتها وصور المحتوى وتكوين الصفحات وخط البراند محفوظة. لم تُغيّر إعدادات البريد أو WHMCS أو الحسابات. إعداد أوزان العربية ما زال يُقرأ من CMS، وحالة الفهرسة الخاصة بكل صفحة محفوظة.
